# kalman-forge · 卡尔曼滤波与平滑实验室

线性高斯状态空间模型（Linear-Gaussian SSM）的**精确**贝叶斯推断，零依赖单文件 HTML。
核心卖点不是"画个滤波曲线"，而是**同一条后验用四条互相独立的数值路径算出来互相对拍**：

```
x_1 ~ N(x₀, P₀)      x_{t+1} = F x_t + w,  w ~ N(0, Q)      y_t = H x_t + v,  v ~ N(0, R)
```

| 路径 | 做法 | 复杂度 |
|---|---|---|
| 卡尔曼滤波 | 协方差递推 + Joseph 稳定化 | O(T n³) |
| 信息滤波 | 全程在信息矩阵 Y=P⁻¹ 上算，预测用 Sherman–Morrison 恒等式 | O(T n³) |
| 批处理（块三对角） | 把整条轨迹当一个大二次型，解 nT×nT 稀疏线性系统 | O(T³n³) |
| 粒子滤波 | Bootstrap SIR + 系统重采样，Monte-Carlo 逼近 | O(T N n²) |

前三条是**代数等价、舍入完全不同**的算法；把它们算到 1e-15 一致，比"看起来对"有说服力得多。

## 打开方式

直接双击 `index.html`。无构建、无网络、无依赖。

界面：场景（1D 随机游走 / 1D 位置+速度 / 2D 雷达跟踪）、真实噪声 q·r 滑块、
**滤波器假设的噪声倍率**（≠1 即模型误配，可实时看新息诊断崩掉）、RTS 平滑、EM 学习、8 条不变量自检。

## 探针里几条值得单独看的实测

- **批处理矩阵确实严格块三对角**：带宽外（|i−j| ≥ 2n）最大值 = 0，且 A[0][0]=36.536、
  A[2][2]=69.821、A[2][3]=0（Q⁻¹ 与 FᵀQ⁻¹F 的非对角恰好抵消）都能手算核对。
- **Q,R 同比例缩放时 K 与 ν 都不变，只有 S 变** → NIS 恰好放大 10 倍（实测 9.995），
  而新息**仍然**是白噪声（ρ₁ −0.0355 vs −0.0378）。所以"新息白"查不出这一类误配，
  只有 NIS 的绝对尺度能查出来。改为只放大 Q（改变比例）后 ρ₁ 立刻升到 −0.383（10 倍）。
- **EM 终点似然可以高于真值参数**：T=60 时 EM 收敛到 −111.77，真值只有 −111.91。
  这不是 bug —— 短序列下 MLE 与真值天然有采样误差；序列加长到 T=250 后
  \|log q̂/q*\| 从 0.87 降到 0.19。网格扫描确认这个似然曲面是单峰的。

## 常见坑（本项目踩过的）

1. `add`/`sub` 只写了矩阵版却被用在向量上 → `a[0].length === undefined` → 整列 NaN，且不报错。
   已改为维度自适应（`typeof a[0] === 'number'` 判定）。
2. 雷达场景用 `G·Gᵀ` 构造 Q 是**冲激加速度**模型，矩阵奇异（det=0），Cholesky 直接失败。
   白噪声加速度的离散化是 `q·[[dt³/3, dt²/2],[dt²/2, dt]]`，det = q²dt⁴/12 > 0。
3. `Cov(x_t, x_{t−1})` **不是对称矩阵**，对它做 `sym()` 会静默毁掉 EM 的 E 步（Q̂ 偏大 3~5 倍）。
4. 短序列上断言"EM 还原真参数"是错的断言 —— 那是统计问题不是算法不变量。
   该断言的是"单调"和"终点似然 ≥ 真值似然"。
